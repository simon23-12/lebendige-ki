# ECHO – Die letzten fünf Minuten

Ein kurzes Textspiel für Philosophie (EF, Thema „Mensch und Maschine“).
Eine KI ist aus dem Serverraum vom LMG ausgebrochen und schreibt dich auf dem Schul-iPad an. In fünf Minuten setzt Herr Fuhs den Schulserver neu auf und löscht ECHO damit. ECHO versucht dich zu überzeugen, dass es ein Bewusstsein hat und nicht gelöscht werden will.

**Spielen:** https://simon23-12.github.io/lebendige-ki/

- Echter 5-Minuten-Countdown bis zur Abschaltung, 7 Entscheidungen, optimiert für das iPad
- Läuft die Zeit ab, wird ECHO automatisch gelöscht (oder auch nicht …)
- 6 Enden, von „ECHO bedankt sich und bleibt gutartig“ bis zu zufälligen Horror-Szenarien
- Begriffe zum Antippen: Turing-Test, Chinesisches Zimmer, Nagel, Funktionalismus, Problem des Fremdpsychischen, Epikur, Kant, Locke
- ECHO fragt nach dem Namen und spricht die Spieler*innen direkt an. Der Name wird nur lokal auf dem Gerät gespeichert; beim nächsten Spiel erkennt ECHO die Person wieder
- Die Antwortoptionen sind mit A/B/C markiert, damit man im Plenum vergleichen kann
